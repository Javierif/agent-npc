# Features

The full feature list of claude-npc. For a shorter overview see the [README](../README.md).

| | |
|---|---|
| Living mascot | Walks, sits, sleeps, waves. You can pick it up and drop it: it falls with gravity. Its eyes follow the pointer and it hops if you click it. Transparent window that lets clicks through everywhere except over the character and its panels. |
| Themes | Characters: Postie, plus the alternates Don Rana (frog), Don Pato (duck) and Don Hámster (hamster), each with a jacket, shirt and tie. Four Postie palettes (Postie, Menta, Noche, Tostada), custom themes (one JSON per theme), themes installable by URL and imported **Codex Pets** (see *Themes and pets*). |
| Languages | Español, English, Português, Français and Deutsch; automatic by system language, or manual in Settings. |
| Mini mode | Docks to the right edge of the screen and peeks out; it comes out when there is news or you move the mouse over it. Double-click to turn it on or off, or use Settings. |
| Reacts to Claude Code | Thinking, working (laptop), juggling if there are subagents, alert if it needs you, happy when done, sad if something fails. Fed by Claude Code *hooks*. |
| Permissions | A card next to the NPC: **Allow / Deny**, global shortcuts `Ctrl+Alt+Y` / `Ctrl+Alt+N`, or from Telegram. Claude's questions (`AskUserQuestion`) and plans (`ExitPlanMode`) do not go on that card: you answer them in the session's panel (single- or multiple-choice options, «Otra respuesta…» (Other answer…), «Enviar respuestas» (Send answers); or approve the plan). |
| Sessions | A panel with all your sessions (state, current tool, last message). *Terminal* brings the session's window to the front if it finds it by folder name; otherwise it opens a terminal that resumes it. Click a row (or that session's child, the small copy of the character that is born by itself with each session; *Quitar hijo* (Remove child) dismisses it and it is not born again) to see its detail, with its pending permissions and questions; *Escribir* (Write) sends a message that continues that conversation (`claude --resume`) and is hidden while the session is working. The *Recientes* (Recent) section lists past sessions that Claude saved in `~/.claude/projects`, without repeating the active ones. |
| Quota | Usage rings for the 5 h and 7 d windows and for the context (see *Quota*). |
| Send tasks | You write a task and the NPC launches `claude -p` in the folder you choose, shows progress and leaves the result as a sticky note. *Continuar* (Continue) on a successfully finished task resumes its conversation (`claude --resume`); *Reintentar* (Retry) on a failed one resends the same prompt, folder and session. Answers are shown with basic Markdown (headings, lists, code, tables, links), no HTML. |
| Obsidian | Point it at your vault. Any `- [ ] something #claude` in your notes appears in the panel; with ▶ Claude does it and **writes the answer under the task and marks it done**. The task can carry context: `[[Note]]` (Claude reads that note first) and `📁 folder` (works in that folder); see *Obsidian*. You can also add tasks from the NPC to an inbox (`Claude NPC Inbox.md`). It works on the files, with no plugin. The panel also has buttons for the daily note, search and creating a new note (via `obsidian://` URI), and up to 6 favorite Obsidian commands run with its official CLI (see *Obsidian*). |
| Suggestions for your notes | In *Obsidian → Cerebro* (Brain), it suggests linking mentions of other notes and adding frequent tags to notes that have none. It shows the diff and only writes with *Aplicar* (Apply). See *Cerebro*. |
| Memory | Optional (off by default): your Obsidian vault as memory. Before each NPC task, and in your Claude Code sessions if you enable it, it adds the relevant notes to the context; when a session ends it writes a linked note in `Claude NPC/` and, if you enable it, reflects on it when it closes (lessons, decisions and to-dos) and forges a personality from what it learns about how you work. You can also ask it questions with citations and request a weekly summary and a maintenance report. Over time it forgets (archives, never deletes) what it does not use, consolidates what it learned into principles and habits, and joins the notes it recalls together. See *Cerebro*. |
| Other agents | Bridges for Gemini CLI, Cursor and Codex, and a generic HTTP endpoint (`/agent`) for any other tool (see below). |
| Approve from Telegram | Every permission request reaches the bot with Allow/Deny buttons. |
| Slack and Feishu notices | A notification when a permission is requested and when a session ends. |
| Mobile view | A read-only page (installable as a PWA) with your sessions and the quota, optional and behind a secret link. |
