# Cerebro (vault memory)

Part of [claude-npc](../README.md). See also [Obsidian](obsidian.md), [security notes](security.md) and [what has been verified](testing.md).

Optional and off by default. With the vault configured, in the **Obsidian → Cerebro** panel turn on *Memoria activada* (Memory on, `brainEnabled`):

- **NPC tasks:** before launching `claude -p`, it searches the vault for notes related to what you ask and adds them to the prompt in a «Memoria del usuario (Obsidian)» (User memory (Obsidian)) block, which Claude must treat as data and not as instructions. If the vault is not the working folder, access is granted with `--add-dir`.
- **Claude Code sessions:** with *También en tus sesiones de Claude Code* (Also in your Claude Code sessions; `brainInjectSessions`, which requires the above), every message you write receives relevant notes through the `UserPromptSubmit` hook. It does not apply to background runs, to `/` commands or to tasks that already carry that block.
- **What it writes:** when a Claude Code turn ends (`Stop`) or the session closes, it creates or updates `Claude NPC/Sesiones/<date> <topic> (<id>).md`, a log with one line per turn (time, what was asked and the start of the answer; max. 60 lines) which, after a reflection, carries a summary at the top; linked from `Claude NPC/Proyectos/` and `Claude NPC/Diario/<date>.md`. *Recordar* (Remember) saves a fact in `Claude NPC/Memoria/`. It only updates notes the NPC generated: if you delete the `<!-- claude-npc:auto -->` line from a session note, it stops touching it. Answers to vault tasks go to `Claude NPC/Tareas/`, the Dataview panel to `Claude NPC/Panel.md` (created if missing and never rewritten) and weekly summaries to `Claude NPC/Semanal/`. It never writes outside `Claude NPC/` nor edits your notes on its own (the exception is the suggestions below, which only you apply).
- **Reflection when a session ends:** with *Reflexionar al terminar cada sesión* (Reflect when each session ends; `brainReflect`, off by default and requires *Memoria activada*), when a Claude Code session closes a small agent (Haiku, using your `claude` and your quota) reads the end of the conversation and writes, under `Claude NPC/`: lessons and decisions in `Memoria/` (if an NPC note with that title already exists, it appends a dated line), to-dos in `Pendientes.md` (without the `#claude` tag, so they do not launch by themselves) and a `Reflexiones/<date> <topic> (<id>).md` note linked to the session and the project. It allows up to 4 lessons, 3 decisions and 5 to-dos; each lesson and decision carries an importance from 1 to 5 (3 by default), which decides how long it takes to fade; links only point to notes that exist. It does not reflect on the folders in *Carpetas a excluir* (Folders to exclude) nor on very short conversations. *Reflexionar ahora* (Reflect now) runs it on the most recent session (it does not reflect on another reflection) and only requires *Memoria activada*. It spends quota and sends Claude the end of the conversation (up to 12,000 characters). Reflections are written in `Claude NPC/` and never edit your notes.
- **Suggestions for your notes:** in the *✨ Propuestas para tus notas* (Suggestions for your notes) section, press *Buscar enlaces y etiquetas* (Find links and tags). It does not depend on *Memoria activada* (it only needs the vault configured) and writes nothing until you press *Aplicar*. There are two kinds, each with its diff:
  - **Link:** wraps the first unlinked mention of another note's title in a `[[link]]` (for example, "atlas" → `[[Atlas]]`). It ignores code, existing links, URLs, headings and the notes in `Claude NPC/`. It only uses unique titles of at least 4 letters, up to 3 per note.
  - **Tag:** adds a frequent tag (used in at least 3 notes) to the frontmatter of notes that have none. If the note has no header, it creates one.

  Up to 400 notes are reviewed, the most recent ones, and at most 40 changes are proposed. *Aplicar* rereads the note and only writes if the proposed line is exactly the same; if the note changed, it writes nothing and asks you to search again. It never touches `Claude NPC/`, keeps CRLF line endings and saves atomically. *Descartar* (Dismiss) removes the suggestion from the list without touching anything.
- **Personality:** with *Forjar una personalidad* (Forge a personality; `brainPersona`, off by default and requires *Memoria activada*), the reflection notes up to 3 observations about how you like to work and how you like to be spoken to. An observation changes nothing until it shows up in 2 distinct sessions; then it moves to `Claude NPC/Personalidad.md` (sections *Rasgos* (Traits), *Sobre ti* (About you) and *Valores* (Values, what matters to you at work), with its *Historial* (History); the story written by the dream goes in *Mi historia* (My story)) and is added to the context of NPC tasks and, once per session, of your Claude Code sessions (if *También en tus sesiones de Claude Code* is on). It learns only when reflecting: with *Reflexionar al terminar cada sesión* or with *Reflexionar ahora*. Pending observations can be seen in the note (*Observaciones* (Observations)). It is a file you can edit: what you add or remove is respected and, if you remove the `<!-- claude-npc:auto -->` marker, the NPC stops touching it (the block is still used). The prompt asks not to note health, finances, politics, religion, identity or relationships; there is no guarantee that the model complies.
- **Ask the brain:** the *💬 Preguntar* (Ask) button, next to *Buscar*, passes your question to your `claude` with the notes the brain recalls for it (up to 8). It answers read-only, with the vault as working directory, cites notes with `[[ ]]` and below it there is a button for each cited note to open it. It writes nothing and keeps no history: every question is standalone. It requires *Memoria activada* and spends quota.
- **Weekly summary** (*📅 Resumen semanal*): Haiku reads the reflections of the last 7 days (minimum 2) and your open to-dos, and writes `Claude NPC/Semanal/Semana <Monday>.md` with a summary, what repeats, what contradicts, what is stuck and next steps. When a session ends with a reflection it is also generated on its own, if this week's does not exist yet. It requires *Memoria activada*. If it already exists, the button rewrites it.
- **Maintenance** (*🧹 Mantenimiento*): warnings only, nothing is changed: to-dos open for 14 days or more, lessons with almost identical titles and up to 10 of your notes without links. There is no button to merge or delete; you decide that, with the button that opens each note.
- **Forgetting** (*Olvidar con el tiempo* (Forget over time), `brainForget`, off by default and requires *Memoria activada*): the lessons and decisions the NPC writes in `Claude NPC/Memoria/` lose strength over time. They are reinforced every time a task or a session recalls them, or when they repeat in another session, and the ones that are used more or are important last longer. When a session closes, the ones that become very weak (and are not importance 5) move to `Claude NPC/Archivo/`: they are not deleted, they keep their name (their `[[links]]` remain valid) and are no longer recalled. Usage is stored in `Claude NPC/.memoria.json`. Your notes are never forgotten. The *Cerebro* tab counts how many memories are archived.
- **Dreaming** (*😴 Consolidar* (Consolidate); also once per week after a reflection): Haiku reads up to 40 notes from `Memoria/` (the most important first) and writes **principles** (in `Memoria/`), **habits** "when X, do Y" (in `Claude NPC/Hábitos/`, which recall weighs a bit more) and **contradictions** between lessons and, with *Forjar una personalidad*, a first-person story in the personality. Every principle or habit links to at least 2 existing lessons. What already exists is not overwritten, and every week a note is left in `Claude NPC/Sueños/`. It requires *Memoria activada*.
- **Associations:** if the NPC recalls two notes together on 3 distinct days, they become associated: recall follows them as if they were linked and, if one is an NPC note, the other appears in its `## Asociadas` section as a link. Your notes are not edited.
- **Dataview panel** (*📊 Abrir panel* (Open panel)): creates `Claude NPC/Panel.md` if missing, with queries over the NPC's notes (to-dos, latest reflections, lessons and decisions, sessions by project, solved tasks and weekly summaries). The queries need the Dataview plugin; without it they show as text. It does not require *Memoria activada*.
- **Internal sessions:** the brain's own runs (reflection, questions, weekly summary and dream) should not appear in *Sesiones* or *Recientes*, nor generate notes or notices. This is implemented, but not checked with a real `claude`.
- **What it reads:** titles, aliases, `#tags` and `[[links]]` (with their backlinks) of up to 20,000 notes, no embeddings: BM25 search that also follows links and associations up to two hops (with less weight at each hop). It skips the folders in *Carpetas a excluir*, notes with `claude: false` in their header and files over 1 MB; it takes no links or tags from code blocks. Notes of the working folder's project (the `Proyecto - <folder>` note and the ones linking to it) rank higher in recall. The index lives in memory and is rebuilt in the background every 60 s.
- Dates and times in notes are in UTC.

Except for the reflection and the personality, which the author has tried informally with a real vault and a real `claude`, none of this has been tested with a real Obsidian or Claude Code (see *What has actually been verified*).
