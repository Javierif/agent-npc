# Tests and verification status

Part of [claude-npc](../README.md).

## Tests

```bash
npm run test:ui       # UI: translations complete and consistent in the 5 languages
npm run test          # Rust: hooks, permissions, vault, vault memory (index, recall, capture and log, reflection, personality, forgetting, associations, dreaming), suggestions for your notes, questions to the brain, weekly summary, maintenance, tasks with context (`[[ ]]` and `📁`), panel, Obsidian actions (URIs, command parser), Telegram and webhooks (against simulated servers), bridges, mobile view, themes, claude parser
npx tsc --noEmit      # frontend types
```

To see the UI without Tauri: `npx vite` and open `http://localhost:1420/tests/preview.html` (backend simulated in `tests/mock.ts`).

## What has actually been verified

- **In the real Windows app** (inspecting its webview): the overlay loads, click-through activates only over the character, the hook → card → Allow/Deny → HTTP response flow, the task flow with writing to a temporary vault, Telegram, Slack and Feishu against simulated servers, the Gemini, Cursor and Codex bridges with sample payloads, the `/agent` and `/usage` endpoints, the mobile view on loopback, themes (including a custom one), mini mode, eye tracking, that *Terminal* finds a real window by folder name, importing a (synthetic) Codex pet with each state on its proper animation row, installing a theme by URL, switching language and its persistence.
- **With a stand-in `claude`** that emits the same JSON (`--output-format stream-json`): the runner and the note rewrite. Not with the real model: this environment's session had expired OAuth.
- **Not checked:** Don Hámster (and its own joke) has only been verified with `tsc`, `npm run test:ui` and the preview with `mockIPC`; it has not been seen in the real app. Real Obsidian (only folders in the same format); the *Nota diaria*, *Buscar* and *Nota nueva* shortcuts (`obsidian://`) and the favorite commands through Obsidian's official CLI (`command id=`, Obsidian 1.12.7+): they only have unit tests of the parser, the URIs, id validation and the runner, and the format of `obsidian commands` is an assumption; that real Claude Code, Gemini CLI, Cursor and Codex call the hooks as their documentation says, the `statusLine` in a live session, *Continuar* / *Escribir* (`--resume`) with a real `claude`, also over sessions created in Claude Desktop, login from the NPC (*Iniciar sesión*), global shortcuts pressed on a real keyboard, real Telegram/Slack/Feishu bots, the mobile view from a phone, that a session resumed with `--resume` stays alive during a real task (the background run must not make it disappear from *Sesiones*; fixed, untested in the app), that Windows grants focus when bringing a window to the front (if it refuses, it flashes in the taskbar), macOS and Linux.
- **Only with unit tests and the preview with `mockIPC`** (not with real Claude): answering questions (`AskUserQuestion`, with `updatedInput.answers`) and approving plans (`ExitPlanMode`) from the session panel; that Claude Desktop sessions send the `PermissionRequest` hook; the *Recientes* section with a large history; *Reintentar*; the *Ver eventos recibidos* diagnostic with real Claude Desktop events (tested with unit tests and the preview, not with real events); vault memory (*Cerebro*: index, recall, session notes and the context injected through the hook), which only has unit tests and the preview with `mockIPC`: it has not been checked with a real Obsidian or real Claude Code, including that Claude Code accepts `additionalContext` from an HTTP hook and the effect of recall on answers; the suggestions for your notes (links and tags, and *Aplicar* on real notes), which only have unit tests and have not been seen in the preview; the brain improvements of the latest batch (asking the brain with citations, tasks with `[[ ]]` and `📁`, each task's answer note, the Dataview panel, the weekly summary, *Mantenimiento*, hiding internal sessions and per-project relevance): only unit tests and not seen in the preview, so it is not known whether a task's prompt makes Claude read the notes and work in the indicated folder, whether the citations are correct, whether the panel works with Dataview, or whether internal sessions really do not show up in *Sesiones* or *Recientes*. The last batch (forgetting and reinforcement with `brainForget` and `Archivo/`, the log with a summary in session notes, dreaming with principles, habits, contradictions and story, associations, two-hop recall and personality values) only has unit tests: it has not been seen with a real Obsidian or real Claude Code.
- **Informally tried by the author** (no formal record of what was checked): reflection when a session ends (*Reflexionar al terminar cada sesión* and *Reflexionar ahora*) and the personality (*Forjar una personalidad*), with a real vault and a real `claude`. What has not been checked systematically remains unverified: that `--model haiku` and `--allowedTools` behave as expected, that the personality respects privacy, whether observations repeat with sufficiently similar wording to be promoted (matching is almost literal) and the real effect of the block on tasks and sessions.
