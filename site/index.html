claude-npc

A desktop NPC for Claude Code that reacts to what Claude does, asks you for permissions and lets you send it tasks.

⬇ Download for Windows GitHub

MIT · Windows 11 · MVP · UI in es / en / pt / fr / de

Reacts to Claude Code

Thinking, working, juggling subagents, alert when it needs you, happy when done, sad when something fails.

Approve permissions

A card with Allow / Deny, global shortcuts, or approve from Telegram.

Send it tasks

Runs claude -p with your own session. Read-only unless you allow edits.

Obsidian, no plugin

Write - [ ] something #claude and press ▶. The answer lands under the task.

Quota rings

Your 5 h / 7 d usage and the context window at a glance.

Local first

No backend, no telemetry, no accounts. Your claude, your subscription.

Meet the characters

Drawn from code, one base, every pose derived. Click a character to change what it is doing.

Quick start

  1. Run it and hover the character for the menu.
  2. Press Conectar con Claude Code (Connect to Claude Code) in Sessions or Settings.
  3. Restart your open Claude Code sessions.
Run from source 
npm install
npm run tauri dev

Needs Node 20+, Rust, WebView2 and a signed-in claude.

MVP, tested on Windows 11 only; see what has been verified. MIT licensed, the characters are original.
